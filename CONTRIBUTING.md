# Как помогать

Приложение на русском: подписи, проверки и план работы тоже на русском.

Перед запросом на слияние:

```bash
npm run check
```

Не присылайте `server/data/` и не кладите в репозиторий пароли. Новая форма трубки — это пресет в `src/domain/shapes.ts` и те же параметры, которые уже крутит калькулятор, а не отдельная ветка геометрии.

Если шаг цеха зависит от инструмента, он должен смотреть в список верстака и говорить, чем заменить отсутствующее.
