# Трубки

Мастерская для ручных табачных трубок: форма, брусок, каналы, чертёж 1:1 и план работы под те инструменты, которые уже лежат на столе.

A local workshop for handmade tobacco pipes: bowl geometry, blank limits, a 1:1 drawing, and a tool-aware build plan.

## Запуск

Нужен Node.js 22.

```bash
npm install
npm run dev
```

Приложение откроется на `http://127.0.0.1:5173`. Без сервера наработки остаются в этом браузере.

Чтобы люди могли войти и не потерять трубки при очистке браузера, во втором окне:

```bash
npm run server
```

Сервер слушает `http://127.0.0.1:8787`. Vite проксирует `/api` на него. Имя и пароль простые, пароль на диске только в виде scrypt. База — `server/data/db.json`, в git она не попадает.

Это мастерская, не банк. Не выставляйте сервер аккаунтов в открытый интернет без HTTPS и своего прокси.

## Что внутри

- Готовые формы и калькулятор своей трубки от бруска.
- Стенка, канал, гнездо и цапфа проверяются до того, как форма станет невыполнимой.
- Чертёж сбоку, сверху и в разрезе, развёртка 1:1.
- Цех: схема шага, какие инструменты есть, чеклист по трубке.

Единицы — миллиметры. Угол считается от чубука к чаше: чем меньше, тем сильнее чубук задран. Чубук из бриара прямой, гнётся мундштук.
